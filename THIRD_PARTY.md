# Third-party components

The LICENSE file applies to original study-specific code and documentation in this repository. It does not grant rights to third-party software or datasets.

The repository contains an SSD4Rec adapter and experiment code, not the upstream SSD4Rec implementation or its compiled Mamba and causal-convolution dependencies. The upstream project is https://github.com/ZhangYifeng1995/SSD4Rec; the experiment used commit bdbfe5193f3a6697bb6ee0699ab43386d80c6198. Obtain that implementation and its dependencies from their respective providers and follow their licenses. The included adapter is not a replacement implementation of BiSSD.

MEANTIME is used as a diagnostic baseline. Its third-party implementation is not redistributed; model-specific reruns require the corresponding upstream dependency.

Amazon Reviews and the Yelp Open Dataset are not included. Follow the data providers' current access and reuse terms. Bibliographic citations for the compared architectures are in the paper.
